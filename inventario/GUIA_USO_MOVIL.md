## 📱 Cómo Usar en Móvil

### **1. Acceso Inicial**

#### Desde el Navegador:
1. Abre Chrome, Safari o Firefox en tu móvil
2. Ve a: `https://tu-dominio.com`
3. Inicia sesión con tus credenciales
4. El sistema se adaptará automáticamente

#### Agregar a Pantalla de Inicio (Recomendado):
**En iOS (iPhone/iPad):**
1. Abre Safari
2. Toca el botón "Compartir" (cuadro con flecha)
3. Selecciona "Agregar a pantalla de inicio"
4. Confirma el nombre y toca "Agregar"

**En Android:**
1. Abre Chrome
2. Toca el menú (⋮)
3. Selecciona "Agregar a pantalla de inicio"
4. Confirma y toca "Agregar"

### **2. Navegación en Móvil**

#### Dashboard:
- **Estadísticas:** Tarjetas apiladas verticalmente
- **Búsqueda:** Campo de búsqueda de ancho completo
- **Botones:** Botones de acción apilados verticalmente
- **Tabla:** Desliza horizontalmente para ver todas las columnas

#### Tablas:
- **Scroll Horizontal:** Desliza el dedo hacia los lados
- **Ver Detalles:** Toca cualquier fila para más información
- **Acciones:** Botones grandes y fáciles de tocar

#### Modales:
- **Formularios:** Campos optimizados para teclado móvil
- **Cerrar:** Toca la X o fuera del modal
- **Scroll:** Desliza dentro del modal si es necesario

### **3. Funciones Principales en Móvil**

#### Registrar Serial:
1. Toca "Registrar Serial"
2. Selecciona categoría (lista desplegable)
3. Selecciona modelo
4. Ingresa código de serial
5. Toca "Registrar"

#### Agregar Producto:
1. Toca "Producto Nuevo"
2. Completa el formulario
3. Usa el teclado virtual
4. Toca "Guardar Producto"

#### Buscar Productos:
1. Toca el campo de búsqueda
2. Escribe marca, modelo o SKU
3. Los resultados se filtran automáticamente
4. Toca "Buscar" o Enter

#### Ver Seriales:
1. Desliza la tabla horizontalmente
2. Toca el número de stock
3. Se abre modal con detalles
4. Desliza para ver todos los seriales

#### Imprimir Reporte:
1. Toca "Imprimir Reporte"
2. Espera a que se genere
3. Selecciona "Guardar como PDF"
4. Guarda en tu dispositivo o comparte

## 🔧 Solución de Problemas Móviles

### **Problema: Botones Muy Pequeños**
**Solución:**
- Rota el dispositivo a horizontal
- Usa zoom (pellizca la pantalla)
- Verifica que no estés en modo zoom del navegador

### **Problema: Tabla No Se Ve Completa**
**Solución:**
- Desliza horizontalmente con el dedo
- Rota a orientación horizontal
- Verás el mensaje "← Desliza para ver más →"

### **Problema: Teclado Cubre Campos**
**Solución:**
- El sistema auto-scroll al campo activo
- Cierra el teclado y vuelve a abrir
- Rota el dispositivo

### **Problema: Página Se Carga Lenta**
**Solución:**
- Verifica tu conexión a internet
- Cierra otras pestañas del navegador
- Limpia caché del navegador
- Usa WiFi en lugar de datos móviles

### **Problema: No Puedo Hacer Zoom**
**Solución:**
- El zoom está limitado para mejor UX
- Usa el zoom del navegador (menú)
- Ajusta tamaño de fuente en configuración

### **Problema: Modal No Se Cierra**
**Solución:**
- Toca la X en la esquina
- Toca fuera del modal
- Usa el botón "Cancelar"
- Recarga la página si persiste
